# 草野球スコア記録

1試合分の打数・安打数を選手ごとに登録し、**打率（安打数 ÷ 打数）を自動計算して一覧表示**する最小構成のWebアプリです。
メモ用紙への記入 → Webサイトへの転記、という二重入力をなくすことを目的にしています。

- 利用者: チームメンバー（自分含む）
- 技術: HTML / CSS / JavaScript（フレームワーク・サーバー不要）
- 保存: ブラウザの `localStorage`（このブラウザ内にのみ保存。ログイン・デバイス間同期はなし）

## 今回作った機能（完了条件）

1試合分について **選手名・打数・安打数** を登録すると、**打率が自動計算されて一覧表示** されます。

- 選手名・打数・安打数を入力（1試合につき複数選手をまとめて登録可能）
- 「＋ 選手を追加」で入力行を増減
- 打率一覧を出力（安打数 ÷ 打数、**小数点第3位**まで。打率の高い順に表示）
- チーム合計（合計打数・合計安打・チーム打率）も表示
- 入力内容は `localStorage` に自動保存され、再読込しても復元される

## 今回は作らない機能

- 投手成績（失点等）の記録
- ログイン機能
- 複数デバイス間のデータ同期

## 実行方法

サーバーは不要です。次のいずれかで開けます。

- **かんたん**: `index.html` をダブルクリックしてブラウザで開く
- **ローカルサーバー（任意）**: リポジトリのフォルダで以下を実行し、表示されたURLをブラウザで開く
  ```bash
  python3 -m http.server 8000
  # → ブラウザで http://localhost:8000/ を開く
  ```

## 使い方

1. 「1. 入力」欄に **選手名・打数・安打数** を入力する（足りなければ「＋ 選手を追加」で行を増やす）
2. 「**登録して打率を計算**」ボタンを押す
3. 「2. 打率一覧」に、選手別の打率（小数点第3位まで）とチーム合計が表示される
4. 内容はブラウザに保存され、次に開いたときも復元される
5. 消したいときは「**全データ消去**」ボタンを押す

### 入力チェック（不正な入力の防止）

- 選手名は必須
- 打数・安打数は「0以上の整数」
- 安打数が打数を超える入力はエラーにする（例: 打数3 で 安打4 は登録不可）
- 打数が 0 の選手は打率を計算できないため「----」と表示する

## 動作確認手順

1. `index.html` をブラウザで開く
2. 例として次を入力して「登録して打率を計算」を押す

   | 選手名 | 打数 | 安打数 | 期待される打率 |
   |--------|-----:|-------:|---------------:|
   | 田中   | 10   | 3      | 0.300 |
   | 佐藤   | 3    | 1      | 0.333 |
   | 鈴木   | 4    | 0      | 0.000 |

   → 打率一覧が「佐藤 0.333 / 田中 0.300 / 鈴木 0.000」、チーム合計が「打数17・安打4・打率0.235」と表示されれば成功
3. ブラウザを再読込（リロード）しても、入力と一覧が保持されていることを確認する
4. わざと「安打数 > 打数」を入力し、エラーメッセージが出ることを確認する

## 検証方法（PBL）

- **① 入力時間の比較**: 「メモ用紙記入 → Webサイト転記」の所要時間と、本アプリへ「直接入力」する所要時間を計測して比較する（二重入力の削減効果を確認）
- **② 打率の照合**: アプリが自動計算した打率を、手計算（安打数 ÷ 打数）の結果と照合する
